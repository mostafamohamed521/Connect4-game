# 🎮 Connect4 Game

A Python implementation of the classic **Connect Four** game using `pygame`.

---

## 🧠 About

This is a simple graphical Connect Four game written in Python.  
Players take turns dropping colored discs into a 7×6 grid. The first player to connect four pieces horizontally, vertically, or diagonally wins!

---

## 🛠️ Requirements

✔ Python 3  
✔ pygame
